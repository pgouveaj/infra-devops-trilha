# Módulo 1 - Redes, Linux e Expressões Regulares

## Objetivo

Apresentar os fundamentos de redes de computadores, o uso básico do Linux e a aplicação de expressões regulares para busca e validação de dados.

## Conteúdos abordados

- conceitos de redes, protocolos e camadas;
- endereçamento IP, máscaras, sub-redes e gateway;
- switches, roteadores, VLANs, DHCP, DNS e NAT;
- protocolos de roteamento RIP, OSPF e BGP;
- IPv4, IPv6 e técnicas de transição;
- redes Wi-Fi, segurança, EAP, mesh e interferência;
- comandos básicos do Linux e edição de arquivos;
- permissões, scripts e instalação de programas;
- expressões regulares para localizar, validar e substituir informações.

## Resultado do aprendizado

Ao final do módulo, foi possível compreender a comunicação entre dispositivos, realizar configurações básicas de rede, utilizar o terminal Linux e criar padrões com expressões regulares.
