# Módulo 2 - Linux, Automação, Git e VS Code

## Objetivo

Desenvolver conhecimentos práticos de Linux, criação de scripts Bash, monitoramento de sistemas e controle de versão com Git e GitHub.

## Conteúdos abordados

- navegação e manipulação de arquivos no Linux;
- gerenciamento de pacotes, processos e permissões;
- acesso remoto a servidores com SSH;
- criação de scripts Bash;
- uso de variáveis, condições, laços e funções;
- processamento de textos com grep, sed, awk, sort e outros comandos;
- análise de logs e monitoramento de disco, memória e CPU;
- automação com cron, serviços e timers do systemd;
- Git e GitHub para versionamento e colaboração;
- branches, merge, rebase, tags, releases e resolução de conflitos;
- integração do Git e GitHub com o VS Code.

## Resultado do aprendizado

O módulo permitiu administrar ambientes Linux, automatizar rotinas, analisar recursos do sistema e organizar projetos com Git, GitHub e VS Code.
