# Módulo 3 - Automação Bash e Docker

## Objetivo

Criar scripts Bash para automatizar verificações e utilizar Docker para empacotar e executar aplicações em containers.

## Conteúdos abordados

- criação de scripts com extensão `.sh` e shebang;
- uso de variáveis, parâmetros e validações;
- estruturas `if`, `else`, `for` e `while`;
- criação de funções e buscas recursivas;
- verificação de conflitos de merge com grep;
- monitoramento de aplicações com curl;
- acompanhamento do uso de disco;
- criação de logs e agendamento com crontab;
- criação de imagens com Dockerfile;
- execução, versionamento e publicação de imagens;
- uso do Docker Hub;
- configuração de múltiplos serviços com Docker Compose;
- portas, volumes, redes e variáveis de ambiente.

## Resultado do aprendizado

Ao final do módulo, foi possível criar scripts de automação e executar aplicações de forma padronizada com Docker e Docker Compose.
