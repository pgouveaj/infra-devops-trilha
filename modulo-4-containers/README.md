# Módulo 4 - DevOps, Web, Containers e APIs

## Objetivo

Apresentar práticas de DevOps relacionadas a Linux, comunicação web, Git, integração contínua, containers, servidores Nginx e APIs.

## Conteúdos abordados

- administração Linux, scripts Shell e tarefas agendadas;
- funcionamento de URLs, DNS, HTTP e HTTPS;
- métodos, cabeçalhos, cookies, sessões e códigos de status;
- certificados digitais, SSL/TLS, TCP, UDP, QUIC e HTTP/3;
- Git, GitHub, branches, issues e Pull Requests;
- pipelines com GitHub Actions;
- proteção de branches e Dependabot;
- criação de imagens e containers Docker;
- volumes, Docker Compose e implantação na AWS;
- configuração do Nginx como servidor web e proxy reverso;
- balanceamento de carga, cache, FastCGI e HTTPS;
- APIs REST, SOAP, GraphQL, gRPC e webhooks;
- comunicação em tempo real e documentação com OpenAPI.

## Resultado do aprendizado

O módulo forneceu uma visão ampla do fluxo DevOps, desde a administração de servidores até a entrega de aplicações web e APIs.
