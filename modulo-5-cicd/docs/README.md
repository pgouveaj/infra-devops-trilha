# Módulo 5 - Docker, CI/CD e Observabilidade

## Objetivo

Criar ambientes conteinerizados, automatizar testes e builds e acompanhar aplicações por meio de métricas, dashboards e alertas.

## Conteúdos abordados

- containers, imagens e Dockerfiles;
- namespaces, cgroups e ciclo de vida dos containers;
- portas, volumes, bind mounts e tmpfs;
- redes Docker e Docker Compose;
- automação de testes com Makefile e Docker Compose;
- criação de pipelines com GitHub Actions;
- lint, compilação, testes e matrizes de execução;
- proteção da branch principal e uso de Pull Requests;
- geração e reutilização de artefatos;
- build e publicação automática de imagens Docker;
- proteção de credenciais com GitHub Secrets;
- métricas com Actuator, Micrometer e Prometheus;
- consultas com PromQL;
- dashboards no Grafana;
- alertas com Prometheus, Alertmanager e Slack.

## Resultado do aprendizado

Ao final do módulo, foi possível integrar containers, pipelines e observabilidade em um fluxo próximo ao utilizado em ambientes DevOps.
